# Founding Creator Program

> [!TIP] This is the solution to the cold start problem. 9 of 50 founding creator spots are already shown as claimed in the platform (seeded data). The visual scarcity drives real applications.

---

## What Founding Creators get

| Perk | Details |
|------|---------|
| Lifetime Pro — free | Never pays for Pro subscription |
| Founding Creator badge | Permanent amber badge on profile |
| First 50 spots visible | Public counter on the /founding-creators page |
| Featured placement | Their apps appear in homepage sections |
| Direct access to founder | Private Discord channel or email thread |
| Revenue from day 1 | Paid fork pricing available immediately |
| Input on roadmap | Vote on feature priorities |

---

## Who to target

### Tier 1 — Highest priority
These people have audiences that trust their tool recommendations.

- Vibe coders with 1k–20k followers on Twitter/X
- YouTube creators making "I built X with AI" videos
- Newsletter writers covering AI tools (e.g. The Neuron, TLDR AI)
- Indie hackers with a "building in public" following

### Tier 2 — High value
Smaller audience but high-quality work that elevates the platform.

- Prolific builders in Lovable/Bolt/Replit communities
- People whose apps get a lot of organic engagement
- Educators who teach others to vibe code

### Tier 3 — Anyone who's shipped something great
Quality over follower count. A beautiful app with no audience is still valuable at launch.

## Application form fields (live on /founding-creators)

The page currently collects:
- Name
- Role (chip buttons: Builder, Designer, Educator, Creator, Other)
- "Link to something you've built" (required)
- "Why do you want to be a Founding Creator?" (optional)

**Follow-up flow after form submit:**
1. Send confirmation email via Resend (template TBD)
2. Review submission within 48 hours
3. If approved: send Loom walkthrough link + Discord invite
4. If borderline: reply asking for more context
5. If not a fit: polite decline with "we'll let you know when we launch publicly"
