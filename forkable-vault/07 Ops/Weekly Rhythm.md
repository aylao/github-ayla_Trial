# Weekly Rhythm

> [!NOTE] Designed for a solo founder. The goal is to never miss the things that compound (content, creator relationships, metrics) while leaving most of the week for building.

---

## Monday — Review & plan (30 min)

- Check Plausible: traffic, top pages, referrers
- Check Stripe: MRR, new subscribers, churn
- Check Supabase: new signups, apps submitted, forks made
- Write down this week's single most important thing to build or do
- Review [[Roadmap]] for upcoming milestones

---

## Tuesday — Content (1 hour)

- Write and post "App of the Week" Twitter thread
- Reply to any engagement from last week's posts
- Check in on Founding Creators: anyone worth shouting out?

---

## Wednesday — Build day (most of the day)

- No meetings, no socials
- Focus on the single most important thing from Monday
- Use `/dev` skill to run the dev server and test
- Use `/build-check` skill before ending the day

---

## Thursday — Creator relationships (30 min)

- Reply to any DMs from creators about the platform
- Review new app submissions — approve or request changes
- Send 3–5 new Founding Creator outreach DMs (if spots still open)
- Check the Founding Creator Discord/channel

---

## Friday — Shipping & wrap-up (1 hour)

- Ship whatever was built this week (commit + push + Vercel auto-deploys)
- Write a "building in public" tweet about what shipped
- Post in relevant communities (r/SideProject, Indie Hackers) if milestone was hit
- Add notes to Obsidian vault about what was learned this week

---

## Monthly — Big picture (2 hours, first Monday of month)

- Review MRR vs. projection in [[Revenue Projections]]
- Update [[Cost Tracker]] with actual vs. projected costs
- Update [[Roadmap]] — what moved, what's next
- Write a public "monthly update" thread on Twitter
- Review and adjust [[Go-To-Market Strategy]] based on what worked

---

## What NOT to schedule

These things can wait for when they naturally come up:
- Responding to individual social media comments (reply same-day but don't block time for it)
- Checking email more than twice a day
- Redesigning things that already work
- Feature requests that aren't on the [[Roadmap]]

---

## Tools for this rhythm

| Tool | Use |
|------|-----|
| Plausible | Traffic and page analytics |
| Stripe Dashboard | Revenue metrics |
| Supabase Table Editor | User and content data |
| Obsidian (this vault) | Weekly notes, planning |
| Claude Code | Building and shipping |
| Resend | Creator and user communications |
| Mercury | Business banking |

---

## Signs the rhythm needs to change

- If building is taking less than 3 days/week → you're under-shipping
- If you're spending more than 2 hours/day on social → you're under-building
- If metrics haven't moved in 2 weeks → revisit [[Go-To-Market Strategy]]
- If creator relationships feel neglected → move Thursday block to daily 15 min
